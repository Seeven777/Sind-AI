# Jarvis Next RC4

RC4 is a product-level expansion of Jarvis Next. It consolidates the AI Mesh, durable conversation UX, Mission Control foundations and a real-time 3D HQ while preserving the local-first architecture and the execution verification contract.

## Main entry points

- Companion: `/`
- HQ 3D: `/hq`
- HQ classic: `/hq-classic`
- Mission Control: `/mission-control`
- Agents: `/agents`
- Projects: `/projects`
- Memory: `/memory`
- System: `/system`

## Product principles

- local-first
- optional external services
- explicit permissions
- no unverified success claims
- backend is the source of truth
- core is protected and extensible through versioned capabilities
