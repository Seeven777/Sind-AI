# RC5 Product Vision

## Direction

Jarvis should feel like a personal agent operating system, not a collection of internal dashboards.

The product has three primary surfaces:

1. Companion — the daily conversation and command surface.
2. Mission Control — the operational control plane.
3. HQ — the spatial representation of the live agent system.

## UX principles

- High information density without visual clutter.
- Strong visual hierarchy and readable typography.
- The interface explains state; it does not simulate success.
- Long answers remain fully navigable.
- Every destructive or externally consequential action has a visible policy path.
- The visual HQ is a projection of runtime state.
- Local-first remains the default.
