# Jarvis v12 — Morning Presence

Após aplicar a v12, execute `Upgrade-Jarvis-v12.cmd`.

Para conectar o organizador de tarefas pela primeira vez, execute `Connect-Marketing-Tasks.cmd`. O navegador será usado apenas para criar uma sessão autenticada read-only. O e-mail e a senha são protegidos no armazenamento local do Windows (DPAPI) e não ficam no código do projeto.

Na primeira abertura entre aproximadamente 05:00 e 13:00, o Jarvis executa a sequência matinal automaticamente. Depois disso, use **Briefing do dia** no menu para reproduzir.
